Welcome to my blog! This is my first post.

## Why I'm writing

Writing helps me learn. When I explain something, I find the gaps in what I know. I'll share:

- Things I build and how I built them
- Problems I solved (so future me can find the answer)
- Notes on what I'm learning

## How this site works

This site is built with [Astro](https://astro.build) and hosted for free on Cloudflare Pages.
Every post is a Markdown file, so publishing is as simple as:

```bash
git add .
git commit -m "New post"
git push
```

Thanks for reading! 👋
